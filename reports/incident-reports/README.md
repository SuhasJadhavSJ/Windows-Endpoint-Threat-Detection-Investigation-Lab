# Incident Reports

This directory contains finalized incident reports produced from completed investigations.

Each report should summarize:

1. Incident overview
2. Detection/trigger
3. Evidence
4. Investigation timeline
5. IOC findings
6. MITRE ATT&CK mapping
7. Impact assessment
8. Containment recommendations
9. Detection improvements
10. Analyst conclusion and confidence

No incident should be marked malicious solely because a single event appears suspicious.
